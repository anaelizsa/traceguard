# TraceGuard

## Status
Work in progress — learning project using synthetic data only.

## Problem
Developers and testers need a simple way to view software incidents.

## Intended user
Developers and testers.

## Version 0.1 scope
The first version will return a list of synthetic incidents through
GET /api/v1/incidents. Data will be held in memory and recreated at startup.

## Out of scope
This version will not support creating, updating, deleting, or searching
incidents. Database persistence and automatic error detection are also
out of scope.

## Data policy
This project uses synthetic data only. It does not contain proprietary,
confidential, customer, employer, or production information.
